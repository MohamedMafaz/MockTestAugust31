4. Create a Energy Meter

POST api/meters

Request Body:
{
  "meterSerialNumber": "string",
  "facilityId": 1,
  "locationZone": "string",
  "maxVoltageCapacity": 0,
  "baseTariffRate": 0,
  "installationDate": "2026-09-01",
  "isActive": true,
  "isIndustrial": true,
  "description": "string"
}

Query Parameter:
N/A

Path Parameter:
N/A

Response:
201 Created

Error Handling:
409 Conflict - If there is already a meter with the same serial number
400 BadRequest - If voltage is less than 0
403 Forbidden - If the user is not the Admin
401 Unauthorized - If the user didn't passed the valid JWT token

-----------------------------------------

Query Parameter:
N/A

Response:
200 OK

Error Handling:
404 Not Found - If there is no energy meter on the given id
400 Bad Request - If the id mismatch on path parameter and the request body
403 Forbidden - If the user is not the admin
401 Unauthorized - If the user didn't passed the valid JWT token

6. Delete an energy meter

DELETE api/meters/{id}

Path Parameters:
id (int, required)

Query Parameter:
N/A

Request Body:
N/A


Response:
200 OK - Soft deletes the meter (making it inactive)

Error handling:
404 Not Found - If there is no energy meter with the given id
409 Conflict - If there is an already in a pending status for that energy meter
403 Forbidden - If the user is not the admin
401 Unauthorized - If the user didn't passed the valid JWT token

N/A
